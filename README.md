# 📊 Organizador de Declaração de Imposto de Renda

Organizador de Declaração de Imposto de Renda feito em Excel, para reunir e
organizar dados do IR (rendimentos, bens, dívidas e deduções). Tem menu de
navegação entre abas, lista suspensa para validação de dados e um resumo com
totais calculados. Projeto do Bootcamp Santander - Excel com IA e Claude (DIO).

## Funcionalidades

- Menu de navegação entre as abas
- Lista suspensa para validação de dados
- Resumo automático com totais
- Datas anotadas manualmente pelo usuário

## Como usar

1. Baixe o arquivo da planilha
2. Abra no Excel (2016 ou superior)
3. Preencha os dados navegando pelo menu
