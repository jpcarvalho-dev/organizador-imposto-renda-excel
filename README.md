# organizador-imposto-renda-excel
Organizador de Declaração de Imposto de Renda feito em Excel, para reunir e organizar dados do IR (rendimentos, bens, dívidas e deduções). Tem menu de navegação entre abas, validação automática de dados e um resumo com totais calculados. Projeto do Bootcamp Santander - Excel com IA e Claude (DIO).
